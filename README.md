# Game Dev Portfolio

React portfolio site for Michel van der Linden, built with Vite.

## Available Scripts

Run these commands from the project directory:

### `npm start`

Starts the Vite development server. Open the URL printed in the terminal.

### `npm test`

Runs the test suite once with Vitest.

### `npm run build`

Builds the production site into the `build` folder.

### `npm run deploy`

Builds the site and publishes the `build` folder to GitHub Pages.
